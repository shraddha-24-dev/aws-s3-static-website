# AWS S3 Static Website Hosting

## Project Overview

This project demonstrates how to host a static website using Amazon S3.

## AWS Services Used

- Amazon S3
- IAM
- S3 Bucket Policy

## Technologies

- HTML
- CSS
- AWS
- Git
- GitHub

## Implementation

1. Created an S3 bucket.
2. Uploaded website files.
3. Enabled static website hosting.
4. Configured bucket permissions.
5. Configured index.html as the index document.
6. Tested the website using the S3 website endpoint.

## Result

Successfully deployed a static website using Amazon S3.

## Website Status

The website files are currently hosted in this GitHub repository.
AWS S3 static website deployment is planned as the next step.
